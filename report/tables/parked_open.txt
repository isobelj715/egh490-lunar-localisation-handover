The L0 row is the control: if it reads millimetres, the window really was
still, and every larger number in that run is error owing nothing to a
reference trajectory.

Read the two halves against each other. A closing window far worse than the
opening one means the error is not a startup transient -- it is still being
accumulated at the end of the drive, by which point the map itself is wrong.
Quote the opening window on a slide, because the L0 control makes it airtight,
and quote the closing window when asked whether it stays that good.
