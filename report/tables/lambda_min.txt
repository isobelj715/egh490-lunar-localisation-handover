Each point is the median over every scan in that level of that run, so a line is
one recording and the x-axis is how much of the scene was deleted before it
was replayed. The same physical drive underlies all four points on a line.

Stock runs only, by default. A brake-off build's lambda_min differs a little,
because suppressing the update changes the pose and so which correspondences
get selected -- put both on one axis and you are no longer comparing scenes.
Pass those directories by name if you want them anyway.
