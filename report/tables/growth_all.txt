Grey bands are where the rover is stationary, taken from the baseline. True
displacement there is zero, so a curve that climbs inside a band is error you
can state without any reference trajectory at all -- and the height of the
left-hand band should match that run's opening value in parked_bars.py.



The right-hand endpoint should match brake_effect.py for the same run and
level, because it is the same measurement at the same instant.

MIND THE GAP BETWEEN "final" AND "peak". Every headline number in this
campaign is the value at the end of the run, which is a convention, not a
worst case. Where peak is several times final, the curve wandered and the
endpoint caught it on the way down -- quote both, or quote the peak and say
so. A reader looking at the figure will see the peak whatever the table says.

READING THE SHAPE. A curve that rises steadily with distance is accumulating
bias. A curve that steps once and then runs flat took its error in a single
event -- look at what happened at that distance rather than blaming the drive
as a whole. A curve that stays flat all run is not accumulating at all, which
is the claim worth making about level 2 and cannot be shown with endpoints.

Do NOT convert these to a percentage of path length. That framing assumes the
error grows with distance, which is the very thing this figure tests -- and in
this campaign the longest run is not the worst.
